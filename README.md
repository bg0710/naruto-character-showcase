# Naruto Character Showcase

A Naruto-themed frontend webpage designed to showcase popular Naruto characters through interactive image cards and hover effects.

## Overview

This project is a simple frontend web design project created to experiment with HTML and CSS styling, image-based layouts, hover interactions, and visual effects.

The webpage presents multiple Naruto characters, including Naruto Uzumaki, Sasuke Uchiha, Itachi Uchiha, Kakashi Hatake, Madara Uchiha, and Obito Uchiha.

## Features

- Character-based image card layout
- CSS hover effects and visual transitions
- Character information display
- Responsive visual layout
- Dark-themed anime-inspired UI

## Technologies

- HTML5
- CSS3
